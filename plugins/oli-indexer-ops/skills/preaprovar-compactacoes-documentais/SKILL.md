# Pré-aprovar compactações documentais

Este alias só é usado por invocação explícita. Leia integralmente o
[`preaprovar-indexacoes`](../preaprovar-indexacoes/SKILL.md), selecione a referência jurídica do
perfil e aplique a camada de
[compactação documental](../preaprovar-indexacoes/references/overlays/compactacao-documental.md).
Não mantenha regra ou autoridade própria neste wrapper.
